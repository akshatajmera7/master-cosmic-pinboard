# Cosmic Corkboard 🪐
### Daily Master Dashboard & Pinboard

A colorful, tactile master dashboard and pinboard inspired by retro-futuristic corkboards and neo-brutalist aesthetics designed with StitchMCP.

## ✨ Features
- **Daily Launcher & Rituals**: Quick jump cards for NYT Wordle, NYT Connections, Daily Lo-Fi Spotify, GitHub commit streaks, and YouTube watchlist.
- **Tilted Idea Stickies & Memos**: Draggable, colorful pastel notes pinned with metallic enamel pushpins and washi tape.
- **Master To-Dos**: Fast rapid task addition, priority tags, and strike-through progress tracking.
- **Live Scratchpad**: Lined paper stream-of-consciousness scratchpad with auto-save.
- **Master Links Shelf**: Categorized bookmarks (Games, Dev, Media, News, Tools, Design) with visit counters and quick launcher.
- **Habit & Streak Tracker**: Active daily streak counters with visual progress indicators.
- **Full Drag & Drop**: Freely organize stickies, widgets, and bookmark tiles.
- **Supabase Real-Time Persistence**: Cloud sync for all links, stickies, and todos.
- **Vercel Deployment**: Live instant deployment.

## 🛠️ Tech Stack
- HTML5, Modern Vanilla CSS, Tailwind CSS CDN
- Space Grotesk, Plus Jakarta Sans, Outfit Google Fonts
- Material Symbols Outlined
- Supabase Real-Time DB & LocalStorage Hybrid
- Vercel Deployment
